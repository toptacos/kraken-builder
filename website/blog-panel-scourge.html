Panel (free) and Scourge (premium)

Free panel shows paths and resources on one box. Scourge is the licensed fleet view: login at kraken.topta.co, list devices in an org scope, share config only after kraken grant.

kraken tentacle add examples/tentacles/panel
kraken run panel status
kraken license set scourge KEY
kraken grant scourge
kraken grant remote_config
kraken tentacle add examples/tentacles/scourge
kraken run scourge status
