Publish a tentacle

A tentacle is a folder with tentacle.yaml and a binary. Same JSON contract on every machine.

name: my-arm
version: "0.1.0"
license: free
binary: handler.py
actions: [ping]

Premium arms set license: premium. Keys live in ~/.kraken/keys.
