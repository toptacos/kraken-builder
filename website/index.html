Why use it

You already have scripts, APIs, and a laptop. Kraken is the one local binary that turns those into named arms with licenses, hooks, and a queue — without standing up another SaaS.

Local first

Runs on your machine. Payload in, JSON out. The cloud is optional for catalog and keys.

Any language

A tentacle is a binary + YAML. Python, Go, Rust, PHP, a shell script — same contract.

Paid arms, free core

MIT core. Premium tentacles check a key. You can sell weather-pro without forking the runner.

Compose, don’t rewrite

Workflows chain responses. Hooks fire before/after. Dependencies resolve before you run.

Privacy default

Payloads stay on the box unless an arm you chose sends them. Keys live in ~/.kraken/keys.

Solo and ops

Ship without four new vendors. Doctor and monitor for the jump host.

Examples

Copy these. They are the same commands on the explainer.

Install and prove the box
curl -fsSL https://kraken.topta.co/install.sh | sh
kraken doctor
ls ~/.kraken
Add a free arm
kraken tentacle add examples/tentacles/geo
kraken run geo lookup --payload '{"ip":"1.1.1.1"}'
Unlock a premium arm
kraken tentacle add examples/tentacles/weather-pro
kraken license set weather-pro YOUR_KEY
kraken run weather-pro forecast --compose
Sequence two arms
kraken workflow run examples/workflows/geo-then-weather.yaml
# $geo.city interpolates into weather-pro
Dev env + hotreload
kraken tentacle add examples/tentacles/docker-env
kraken tentacle add examples/tentacles/hotreload
kraken workflow run examples/workflows/dev-loop.yaml
Encrypt and hand off
kraken tentacle add examples/tentacles/vault
kraken tentacle add examples/tentacles/store
kraken workflow run examples/workflows/secure-share.yaml
