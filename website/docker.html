Docker flags Kraken actually sets

Core stays lean. Only runtime, docker-env, and sites shell out to Docker.

runtime

docker run --rm -i
  --network kraken_dev          # name must start with kraken_
  --security-opt no-new-privileges
  -v $PWD:/work
  -v ~/.kraken/data:/kraken/data:ro   # drop :ro if write_data
  image:tag                     # :latest rewritten to :local

docker-env

kraken run docker-env plan --payload '{
  "name":"dev",
  "public":false,
  "isolated":true,
  "services":[{"name":"redis","image":"redis:7-alpine","ports":["6379:6379"]}]
}'

Publishes become 127.0.0.1:6379:6379. isolated:true sets Compose internal: true.

User namespaces

Not a tentacle flag. Run rootless Docker as your user, or set userns-remap on the daemon. Do not pass --userns=host from Kraken — that turns remapping off. See docs/USERNS.md.
