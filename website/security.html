Tentacle security

Tentacles run as you. Core does not jail them. Isolation is the JSON contract plus Docker flags when a tentacle asks for a container.

Trust

you
 ├── core (config, licenses 0600, hooks)
 ├── arms/  (in-process — do not install strangers here)
 └── tentacles/  (subprocess, JSON in / JSON out)
      └── optional docker  kraken_*  bind 127.0.0.1

Do

  • Only tentacle add repos you would make install.
  • chmod 700 ~/.kraken.
  • Keep public: false on compose.
  • Treat kg_ group keys like a household password.

Do not

  • Expose the CLI over HTTP.
  • Rely on XOR vault fallback.
  • Ship KRAKEN_LICENSE_OFFLINE=1 in a SaaS wrapper.
