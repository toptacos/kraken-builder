# Who this is for

Positioning that matches the code: a local runner, not a cloud agent platform.

## Jobs to be done

1. **Homelab operator** — One Pi, a NAS, a laptop. `pi-net` finds the board, `sites` plans two nginx boxes on `127.0.0.1`, `filesort` hashes the photo dump. Docker only when `up` runs.
2. **Indie who sells a data arm** — Ship `weather-pro` in its own repo. Buyer already has `kraken`. You never fork core. Featured catalog slot is the paid listing.
3. **Consultant / DPI-style ops** — Repeatable `doctor` + workflow on a jump host. Client keeps the MIT binary. You invoice the first three tentacles.
4. **Second-laptop / phone watcher** — Account + ntfy. Phone does not compile. It sees “scan finished.”
5. **Privacy-sensitive shop** — Vault and store stay on disk. `KRAKEN_OFFLINE=1`. No Firebase.

Not for: Kubernetes replacement, Zapier-for-grandma, an LLM that lives in the CLI.

## One-liners for the site

- Install once. Add tools like packages. They stay on your machine.
- Write the tentacle in the language you already compile.
- Pay for data or a second device, never for `kraken doctor`.
