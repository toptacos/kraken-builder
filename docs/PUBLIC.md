# Public input

Kraken CLI is MIT. Third-party tentacles are how the catalog grows.

1. Fork or clone. Copy `examples/tentacles/_template/`.
2. `tentacle.yaml` + a handler that reads JSON on stdin.
3. `PYTHONPATH=. python3 -m kraken tentacle add path/to/folder`
4. Open a Discussion under write-a-tentacle, or POST https://kraken.topta.co/register
5. Listed stays false until review. No keys in the ticket.

Do not open issues for “how do I install.” That is Discussions → install.

Code of conduct: [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)
