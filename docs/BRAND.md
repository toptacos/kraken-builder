## Mark

The tentacle-K lockup on ink. Files in `branding/` and `website/img/kit-2026/`.

## Why this brand exists

Kraken is the product name for a local runner. Tentacles are arms you attach. Teal-on-ink is how the line “one binary, many tentacles” holds in a feed of generic CLI pages.

## Why someone uses the product

1. One install instead of a folder of undocumented scripts.
2. Tentacles stay in their own repos; core stays lean.
3. Free arms and paid arms share the same invoke contract.
4. Workflows and hooks exist so you do not wrap everything in bash again.
5. The machine stays yours — licenses gate features, not your files.

## Examples we show in public

```
kraken doctor
kraken tentacle add examples/tentacles/geo
kraken run geo lookup --payload '{"ip":"1.1.1.1"}'
kraken license set weather-pro YOUR_KEY
kraken workflow run examples/workflows/geo-then-weather.yaml
```

Nyx speaks only those lines. Ads, docs, and the explainer use the same list so the brand does not invent a second product.

## Do not

- Do not use Kraken (the exchange) wordmark or colors.
- Do not put the mark on a neon ocean background for docs.
- Do not put Nyx on other Topta products.
- Do not explain the mythology. Explain the command.
