# Growth — what is wired vs what a human still clicks

## Wired in this tree
- Install → vanilla → `kraken demo` (first JSON)
- Doctor `next` actions
- Live SPA: use-cases, journal, changelog, register, long-form geo/filesort
- Prerender + sitemap on `npm run build` in the SPA
- Homebrew formula `Formula/kraken-cli.rb` (fill sha256 after tagging v0.1.1)
- Discussions templates
- `scripts/publish-journal.sh` — POST journal to blog.topta.co if token present
- `scripts/drip-kraken.sh` — record day 0/2/7 notes in `kraken_contact` (no spam blast)
- CI: demo + doctor on ubuntu/mac/windows

## Human (do not automate)
- Google Search Console verify kraken.topta.co and submit sitemap
- GitHub topics: cli, homelab, raspberry-pi, plugins, local-first, self-hosted
- Claim `@kraken_topta` on X/YouTube if still free — do not inject JS to create accounts
- Post drafts in `docs/SOCIAL.md` from the matt@topta.co Chrome profile after a click
- Fill Homebrew sha256 after `git tag v0.1.1 && git push --tags`
- Product Hunt only after public binary + one paid tentacle

## Do not
- Create new third-party accounts with AppleScript
- Turn on live Stripe from CI
- Put Kraken on the topta.co taco hero as a peer product
- Phone home from free tentacles
