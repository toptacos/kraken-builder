# taco

Premium **TopTaco** Kraken tentacle.  
https://kraken.topta.co · https://api.topta.co  
**One binary. Many tentacles.**

Local gamification ledger. Chat is **`/kraken taco @user`** only.

## Install

See `docs/INSTALL.md`.

```bash
kraken tentacle add ./kraken-tentacle-taco
python3 bin/kraken taco init
```

## Use

```json
{"v":1,"action":"give","payload":{"from":"ada","to":"bev"}}
{"v":1,"action":"event","payload":{"user":"ada","kind":"pr"}}
{"v":1,"action":"score"}
```
