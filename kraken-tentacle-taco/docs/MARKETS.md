# Marketing plans — taco

Company: **TopTaco**. Site: https://kraken.topta.co. API: https://api.topta.co.  
Product: premium Kraken tentacle. Local ledger. Chat command is `/kraken taco @user` only.

One offer, three translations. Do not invent a second product per audience.

---

## 1. Developers (primary)

**Job.** Make merge, review, and security work visible without a SaaS scoreboard.

**Promise.** PRs and closed vulns become tacos on disk. Slack does not steal `/taco`.

**Where.** GitHub Discussions on toptacos/kraken-builder, CLI READMEs, https://kraken.topta.co/use-cases, Dev.to / HN only with a `ping` gist — no growth-hack comments.

**Message.**
- Subject: Your team already has a CLI. Stop exporting kudos to a cloud HR toy.
- Body: `kind=pr` is 3 tacos. `kind=security` is 8. Policy is yours. Ledger is `$KRAKEN_HOME`. License is the only thing that phones https://api.topta.co.

**Proof.** `tests/test_taco.py`, inbound GitHub mapper, `/kraken taco @user`.

**Do not.** Promise Jira sync, promised velocity charts, or “AI that grants tacos.”

**Ask.** Instance SKU $29 / month ≤25 users, then seats.

---

## 2. Real estate agents (secondary, custom kinds)

**Job.** A small office wants a fair count of showings, listings live, and peer thanks — not another CRM.

**Promise.** You define `custom` events: `listing_live`, `offer_in`, `review_five`. The broker sets limits. Nothing listing-related leaves the office disk unless they pick `hosting.mode=toptaco` receipts.

**Where.** Broker-owner Slack (one post), local association newsletters only if they already run Kraken or will accept “install a CLI.” Most agents will not. Target **broker-tech leads** and small teams that already script follow-up, not cold door-knockers.

**Message.**
- Subject: Kudos that do not live in the franchise portal.
- Body: `/kraken taco @sam` after a covering shift. Redeem is a lunch the broker already buys. TopTaco does not take a cut of commission.

**Proof.** `set-policy` custom checks + peer cap.

**Do not.** Scrape MLS. Do not say “CRM replacement.” Do not email blast purchased agent lists.

**Ask.** One instance per office. Rewards stay the broker’s cost.

---

## 3. Families (narrow, honest)

**Job.** A household that already shares a machine wants chore credit without a kid-tracking cloud.

**Promise.** Custom kinds: `dishes`, `homework`, `drive`. Daily caps so siblings cannot farm. Ledger stays in the home directory.

**Where.** Homelab / self-host forums, not parenting Facebook groups. Pitch the **parent who already installed Kraken**, not “an app for families.”

**Message.**
- Subject: Allowance math on the computer you already own.
- Body: No child account at TopTaco. No photos. Redeem is a real reward you fulfill. Command is explicit so it does not collide with other bots.

**Proof.** `per_hour` / `per_day`, `deny_self`, local hosting default.

**Do not.** Market to minors. Do not add location tracking. Do not sell “family subscription with profiles.”

**Ask.** Instance SKU only. No seat upsell on children.

## Shared creative

Use the three marks only: icon, logo, hero. Ink / teal / gold. Line “One binary. Many tentacles.” URL always written in full.

Chat copy never uses bare `/taco`.

## Sequence

1. Developers + OSS — 90% of spend (time, not ads).
2. Broker-tech and agencies that already open a terminal — opportunistic.
3. Families — documentation only, no paid acquisition.

If a segment needs a mobile app or a hosted bot, that is a different product. Do not spend taco margin building it.
