# Kraken

One binary. Many tentacles.

Local-first CLI plugin runner. JSON in → policy → exec → JSON out. MIT core. Premium is fleet + portal, not a fatter CLI.

```
python3 -m kraken init
python3 -m kraken vanilla
python3 -m kraken self plan
```

Site: https://kraken.topta.co  
API: https://api.topta.co  

Not the crypto exchange. Brand: tentacle-K, ink `#0B1220`, teal `#2FD0C6`.
