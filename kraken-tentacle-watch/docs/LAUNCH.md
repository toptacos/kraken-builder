# Launch checklist

1. Tag `v0.1.0` on the public git remote.
2. Point `schemas/catalog.json` `source` at that URL.
3. Follow the shared `KRAKEN_DIRECTORY_PLAN.md`.
4. Catalog blurb: system, user, browser, and media watchers with third-party notify.
5. Commands on the page: `kraken tentacle add <url>` then `kraken run watch ping`.
6. `platforms.*.tested` stays false until that OS executed the binary.
