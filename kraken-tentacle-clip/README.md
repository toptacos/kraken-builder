# clip

Local index of video **share URLs** you paste. Part of the reef.

This arm does **not** log into Facebook, scrape reels, or download video. The share link you sent (`facebook.com/share/r/…`) is stored as a reference plus your title/note/tags.

```json
{"v":1,"action":"add","payload":{"url":"https://www.facebook.com/share/r/1Bwr73ZXXL/","title":"reel","note":"describe it here"}}
```
